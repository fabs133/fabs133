# Fabio-Eric Rempel

Backend developer (Python, C#/.NET) based in Detmold, Germany. IHK-certified Fachinformatiker für Anwendungsentwicklung with close to four years of development work at Weidmüller and KEB Automation.

I build LLM systems where the model drafts and deterministic code checks the result: contracts, postconditions and my own measurement runs instead of demos.
